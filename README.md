# universe-awwwards

Awwwards-style interactive front-end demo — an immersive 3D/WebGL experience with cinematic scroll.

**Stack:** Next.js · React · TypeScript · Three.js (React Three Fiber / drei) · GSAP · Lenis · Framer Motion

## Run locally
```bash
npm install
npm run dev
```
